# stardew-mods

## Sebastian Cabeza de Coco

A [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915) pack for Stardew Valley 1.6.

- **Done:** on about 1 in 3 days, Sebastian ends his daily line with "Cabeza de Coco."
- **Planned:** red hair and brown eyes.

### Install
1. Install [SMAPI](https://smapi.io) and [Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915).
2. Download the zip from [Releases](https://github.com/mperafan/stardew-mods/releases).
3. Extract it into `Stardew Valley/Mods/`, so you end up with `Mods/SebastianCabezaDeCoco/manifest.json`.

### Build
```bash
./scripts/build.sh   # -> dist/SebastianCabezaDeCoco-<version>.zip
```
